# Answer with Books

One skill for a shared library of original texts, question-led reading guides, and source-grounded answers. All book processing runs on the hosted service.

Run `node bin/answer-with-books.js --help` for the current command surface. `books`, `book`, `guides`, and published `guide` readings are public. Use browser `login` for uploads, guide creation and subscriber source access.

The $24/month plan includes 20 new guides per billing month. Uploads are free and public. Original files stay private; the subscriber reader returns source lines rather than downloadable files. Models select passages by reasoning over chapter maps and originals, not keyword or vector ranking.

There is one canonical skill under `skill/answer-with-books/`. No per-book installation, local processing, local API server, source-package download or separate credit purchase is part of the new reading workflow. Historical private-book modules remain outside the distributed runtime while existing receipts and private records are retained by the service.

See the web repository's `docs/product/subscription-and-shared-library.md` for implementation and rollout status. A local build does not imply that this CLI version or subscription checkout has been published.
